# SuperRouter Project

## How to Navigate

- Code files go in `src`
  - Organize pages using folders
- Assets to serve to the user go in `public`
- `output` will hold the built website. This can be moved around as it contains all assets

## How to Build

- `superrouter build <project name>`

## How To Run

- `superrouter run <project name>`
- Navigate to localhost:3000 to see the page
